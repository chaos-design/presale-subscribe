# Ahead 使用手册

[English](./user-guide.en.md)

## 1. 项目介绍

Ahead 是面向产品团队的功能预告与预约订阅系统。用户可以从模板创建活动页、持续编辑
草稿、发布不可变线上快照，并通过公开链接收集预约邮箱和问卷回答。管理端同时提供预约
明细、CSV 导出及访问与转化分析。

Ahead 明确区分草稿和已发布内容：

- 草稿只对项目所有者可见，保存不会影响线上页面。
- 发布会把当前草稿复制为新的公开快照。
- 撤回只停止公开访问，不删除草稿、预约或分析数据。

## 2. 功能概览

- 邮箱密码注册与登录、数字验证码登录、邮箱确认和密码恢复。
- 十六种响应式页面模板，以及桌面、手机和全屏实时预览。
- 标题、文案、倒计时、版块顺序、配色、字体和动效配置。
- JPG、PNG、WebP、AVIF 图片及 MP4、WebM、OGG、MOV 视频上传。
- 简答、单选和多选问卷，可设置必答题并随发布快照锁定。
- 草稿保存、发布、撤回、重新发布和项目删除。
- 预约搜索、详情查看、邮箱复制、单条删除和 UTF-8 CSV 导出。
- PV、UV、转化、来源、设备、地域、参与度和问卷结果分析。
- 未配置 Supabase 时可使用只读演示模式浏览主要界面。

## 3. 使用前准备

### 使用在线部署

普通用户无需安装软件。使用最新版 Chrome、Edge、Safari 或 Firefox 打开部署方提供的
Ahead 地址，并准备一个可以接收确认链接或验证码的邮箱。

### 本地安装

自托管或本地体验需要 Node.js 20.9 或更高版本、pnpm 11.21.0 和一个 Supabase 项目。

```bash
pnpm install --frozen-lockfile
cp .env.example .env.local
```

在 `.env.local` 中填写：

```dotenv
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=your-publishable-key
```

随后在 Supabase SQL Editor 中整份执行 `supabase/platform.sql`，按
[部署手册](./deployment-guide.md) 配置认证回调和邮件模板，再启动：

```bash
pnpm dev
```

访问 [http://localhost:4433](http://localhost:4433)。不创建 `.env.local` 也可以启动，
但此时为只读演示模式，创建、保存和发布不会持久化。

## 4. 注册、登录与找回密码

### 注册

1. 打开登录页并切换到 **创建账号**。
2. 输入邮箱、密码和确认密码。
3. 阅读并同意服务条款与隐私政策。
4. 提交后打开确认邮件中的链接。
5. 回到 Ahead 后进入工作台；若会话未建立，使用已确认账号重新登录。

密码至少 8 个字符，并应满足页面显示的强度要求。

### 登录

- **账号密码**：输入已确认的邮箱和密码。
- **邮箱验证码**：输入已注册邮箱，获取数字验证码后完成验证。成功发送后 60 秒内不能
  重发；验证码位数和有效期由部署方的 Supabase 配置决定。

两种方式都要求先同意服务条款与隐私政策。验证码登录不会为未注册邮箱创建账号。

### 找回密码

1. 在密码登录页点击 **忘记密码**。
2. 输入注册邮箱并提交。
3. 打开恢复邮件中的链接。
4. 设置并确认新密码，然后重新登录。

## 5. 工作台

登录后可以使用以下入口：

- **总览**：查看项目数、已发布快照、累计预约和近期项目。
- **项目**：集中管理草稿与已发布项目。
- **数据分析**：按项目和时间范围查看访问、转化和问卷数据。
- **模板**：浏览完整页面模板，并从指定模板创建项目。
- **账号设置**：修改工作台显示名称；登录邮箱暂不支持在应用内修改。

点击草稿卡片会直接进入编辑器。点击已发布卡片会进入预约详情；需要修改时使用卡片上的
**编辑** 按钮。

## 6. 创建项目

1. 在工作台点击 **创建项目**，或在模板库点击 **使用此模板**。
2. 输入 2 到 80 个字符的项目名称。
3. 选择页面模板并查看实时预览。
4. 点击 **创建并进入编辑**。

系统会生成稳定的公开 slug。模板只是初始内容和视觉方案，创建后仍可切换。

## 7. 编辑预约页

编辑器左侧按页面区域组织配置，右侧显示实时预览。主要设置包括：

- 项目名称、公开地址和完整页面模板。
- Header 品牌、首屏标题、说明文案和行动按钮。
- 倒计时日期及精确到秒的时间。
- 背景图片的位置和预览视频的自动播放、静音、循环设置。
- 核心亮点、长文案、发布节奏与预约区域。
- 页面区域是否显示及拖动排序。
- 十六种预设颜色、自定义强调色、字体和动效强度、速度与行为。

点击预览中的可编辑区域可定位到对应设置。使用顶部的桌面、手机和预览模式检查实际
效果；全屏预览适合发布前复核完整页面。

### 媒体要求

- 图片：JPG、PNG、WebP 或 AVIF，最大 8 MB。
- 视频：MP4、WebM、OGG 或 MOV，最大 100 MB。
- 上传视频时浏览器会自动截取封面。
- 演示模式只创建当前浏览器会话可见的本地预览，不会上传文件。

### 配置问卷

1. 开启问卷。
2. 设置问卷标题和说明。
3. 添加简答、单选或多选题，并按需要设为必答。
4. 单选和多选题至少保留 2 个选项，每题最多 8 个选项。
5. 每份问卷最多 6 道题，可调整问题顺序。

发布后，问卷结构随线上快照锁定。后续草稿修改不会改变当前公开页或既有答卷的展示
依据，直到再次发布。

## 8. 保存、发布与撤回

- **保存草稿**：只更新编辑版本。
- **发布**：保存当前配置，并将其复制为新的线上快照。
- **复制分享链接**：复制稳定的 `/p/[slug]` 地址；草稿链接不会对外开放。
- **撤回上线**：停止公开访问，保留项目和已有数据。
- **重新发布**：使用最新草稿替换线上快照，公开地址保持不变。

发布前建议同时检查桌面和手机预览、倒计时时区、问卷必答规则、图片裁切和视频播放。

## 9. 管理项目与预约

### 项目操作

项目卡片的操作菜单提供发布、撤回、复制链接、编辑和删除等命令。删除项目会永久删除
项目配置、媒体文件、访问数据和全部预约邮箱，且无法撤销。需要保留名单时，应先导出
CSV。

### 预约管理

只有已发布项目提供预约名单：

1. 打开已发布项目详情。
2. 使用搜索框按邮箱、来源、活动标记、地域、时区或浏览器语言筛选。
3. 点击表格行打开详情抽屉，查看参与度、访问路径、地域、设备和答案。
4. 使用行尾操作复制邮箱或删除单条预约；行尾操作不会打开详情抽屉。
5. 点击 **导出 CSV** 下载当前项目的完整预约数据。

同一项目下重复提交相同邮箱不会创建重复记录。CSV 使用 UTF-8 编码并对电子表格公式
注入做了转义。

## 10. 查看数据分析

进入 **数据分析**，选择已发布项目和时间范围，可以查看：

- PV、UV、预约量和转化率。
- 逐日访问、浏览频次和申请转化明细。
- 来源渠道、设备类型、邮箱域名和地域分布。
- 访客、会话与申请之间的转化效率。
- 有效停留时间、滚动深度、交互次数和回访情况。
- 单选、多选等问卷回答分布。

分析数据只来自已发布页面。浏览器启用 Do Not Track 时不会上报访问行为。Ahead 不保存
IP 地址或原始 User-Agent；地域优先使用部署平台提供的粗粒度请求头，缺失时由服务端
临时解析 IP，并只保存国家、地区和城市。

## 11. 访客预约流程

访客打开 `/p/[slug]` 后：

1. 浏览已发布页面和倒计时、图片或视频内容。
2. 输入受支持的常用邮箱。当前支持 Gmail、Outlook、Hotmail、Live、MSN、Yahoo、
   iCloud、Me、Mac、Proton、QQ、Foxmail、163、126、Yeah、Sina、Sohu、139、189 和
   Aliyun 邮箱域名。
3. 完成所有必答问卷，选择题答案必须来自页面选项。
4. 提交后查看成功提示。

页脚中的 Ahead 署名和 GitHub 图标指向 Ahead 项目本身，不属于活动模板或发布快照。
链接由部署方在 `src/lib/product-config.ts` 的 `productCredit.githubUrl` 中配置。

## 12. 常见问题

### 为什么保存后公开页没有变化？

保存只更新草稿。确认预览无误后再次点击 **发布**，线上快照才会更新。

### 为什么公开链接显示页面不存在？

项目可能仍是草稿、已撤回，或 slug 不正确。到项目库确认状态并重新复制分享链接。

### 为什么找不到草稿项目的预约名单？

草稿没有公开入口，也不会收集预约。首次发布后才会生成预约名单入口。

### 为什么收不到确认邮件、验证码或重置邮件？

先检查垃圾邮件和邮箱地址。验证码 60 秒后可重发；链接失效时重新发起请求。若始终
收不到，请联系部署管理员检查 Supabase 邮件模板、发送限制和 Redirect URLs。

### 为什么登录后又回到登录页？

确认邮箱已经验证，浏览器允许本站 Cookie，并检查访问域名是否在 Supabase Redirect
URLs 中。仍失败时清除本站会话后重新登录。

### 为什么无法上传媒体？

确认登录状态有效、格式和大小符合要求，并请部署管理员检查 `campaign-media` bucket、
RLS 策略和账号对当前项目的所有权。

### 为什么没有真实数据，或刷新后修改消失？

当前实例可能未配置 Supabase，正在使用只读演示模式。部署管理员需要完成数据库、认证
和 Vercel 环境变量配置。

### 为什么访问量与预期不同？

Do Not Track 访客不会被统计；拦截脚本、网络中断和所选时间范围也会影响数据。预约量以
成功写入数据库的记录为准。

### 为什么格式正确的企业邮箱仍无法预约？

当前预约入口只接受上文列出的常用邮箱服务商，不接受自定义企业域名。请改用受支持的
邮箱，或联系部署管理员调整邮箱域名策略。

### 为什么不能修改登录邮箱？

当前版本只支持修改显示名称。邮箱变更需要由部署管理员通过受控的 Supabase Auth 流程
处理。

## 13. 注意事项

- 公开页只读取已发布快照；重要修改应先保存并检查预览，再重新发布。
- 删除项目或单条预约不可撤销。涉及业务留档时先导出并妥善保存 CSV。
- `campaign-media` 是公开读取存储桶，不要上传个人隐私、内部资料或机密文件。
- 预约邮箱和问卷答案属于个人数据。部署方应明确告知用途、控制访问权限并遵守适用的
  隐私和数据保留要求。
- 倒计时按编辑者本机时区录入并保存为统一时间，跨时区发布前应使用目标设备复核。
- 不要在问题截图、公开 Issue 或日志中暴露邮箱、访问令牌、环境变量或完整预约数据。

## 14. 联系与支持

- 产品使用或部署问题：在页脚 GitHub 链接对应仓库的 Issues 中搜索或提交问题，并附上
  复现步骤、浏览器版本和已脱敏的错误信息。
- 账号、权限、邮件或生产数据问题：联系当前 Ahead 实例的部署管理员。
- 参与开发：按仓库的[贡献指南](../CONTRIBUTING.zh-CN.md)提交变更。
- 安全或隐私问题：按仓库[安全策略](../SECURITY.zh-CN.md)私密报告，不要在公开 Issue
  中附加密钥或个人数据。

部署方应在上线前把 `productCredit.githubUrl` 配置为实际源码仓库；若页脚仍指向 GitHub
首页，请直接联系部署管理员获取支持地址。
